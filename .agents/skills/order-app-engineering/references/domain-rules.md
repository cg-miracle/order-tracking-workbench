# 业务规则

- 澳大利亚场景；货币 AUD，显示两位小数；日期 ISO，邮编字符串。
- Order 与 Shipment 一对多；OrderItem 通过 sku 匹配 Product，通过 shipmentId 关联同一订单的包裹。
- RRP 已含 10% GST。不含税单价 = RRP / 1.10。
- decimal.js 运算：未舍入单价乘数量后行小计 ROUND_HALF_UP 到分；订单小计汇总行小计；GST 为小计的 10%，同样舍入；总额 = 小计 + GST + 运费，不额外加运费税。
- 输入金额用十进制字符串，源数据单位确认后转换为 kg、cm；未知值保持缺失。
- 数量必须为正整数；缺失 SKU 或无效价格不能视为零，金额相关数据有问题时标记无法完整计算。
- 物流查询状态 available、unavailable、not_implemented 与订单状态及承运商状态独立。一个包裹失败不影响其他包裹或订单详情。
- 不伪造实时结果，成功时显示当前状态及最后更新时间。
- 运费未实现时为 A$0.00，明确标注原因；TNT 和实际估算为可选加分项。
- 原始查询结果可能含商业数据，发布前检查；评估原件包含凭据，不复制到仓库。
