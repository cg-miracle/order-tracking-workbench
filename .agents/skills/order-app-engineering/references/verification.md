# 验证要求

阶段 0：安装、typecheck、lint、format:check、test、build；确认健康接口、静态首页和未知 API 的 404。
阶段 1：检查九个 SKU 匹配、重复键、字段、价格、重量和尺寸单位及缺失值，提供不含凭据的报告。
阶段 2：验证含税换算、非整除价格舍入、多订单隔离、缺失商品、非法数量及接口 404。
阶段 3：检查明细、收货地址、占位图、汇总、窄屏、直接详情访问和刷新。
阶段 4：受控响应覆盖成功、超时、鉴权失败、空响应及无效结构；记录真实 API 尝试，不以外部可用性决定测试是否通过。
阶段 5：首次安装启动验证、生产构建、凭据检查和中文说明完整性。

根目录命令：npm run typecheck / lint / format:check / test / build。
不要为简单配置或样式写镜像测试；测试应验证对外行为和业务约束。
每次报告检查的实际结果，失败时不得标记通过。阶段结束停下等审核。
